Monte le son. Sur iPhone, enlève le mode silencieux.

? COMMENT ÇA MARCHE

ZINZIN est un firmware pour le M-VAVE FM-1, un petit synthé de poche. Ici, c'est le vrai firmware, compilé pour le navigateur : le même son, le même écran de 240 × 240 pixels.

LES 4 PISTES

  • BOUM la batterie, MATOU le synthé, MAMMOUTH la basse.
  • BAZAR : des bêtises sur tout le mix (BÉGAIE, RECULE, FIGE, COULE, PLONGE, ÉCRASE).

Touche une piste pour la choisir : les quatre premiers potards et le clavier sont à elle.

LES POTARDS

Glisse le doigt vers le haut (ou la droite) pour monter. Chaque potard bouge plusieurs choses à la fois :

  • BIDOCHE le poids, CHATOUILLE le caractère, MOISI la pourriture, FLEMME la longueur et l'espace.
  • HUMEUR : sept humeurs de l'euphorie à la déprime. La gamme, le rythme et l'écran changent.
  • APÉRO : à quel point tout dérive tout seul. CAFÉINE : le tempo.

LES BOUTONS

  • ZOU lance et arrête. AU PIF invente un motif pour la piste, TOUT AU PIF pour les quatre.
  • PAS : les 16 touches blanches deviennent les 16 pas du motif (touche une fois : note, deux fois : accent, trois : rien). Les noires choisissent ce qui s'écrit (le fût, la bêtise, la note).
  • ENREGISTRE : pendant que ça joue, ce que tu joues s'écrit dans le motif.
  • MUET coupe la piste. CAVE / GRENIER : le clavier une octave plus bas / plus haut.
  • BOUCAN (reste enfoncé) : les quatre premiers potards règlent le volume de chaque piste. BOUCAN puis SAUVE : le compteur d'images en haut de l'écran.
  • SAUVE garde ton morceau dans ce navigateur.

SUR UN ORDI

Espace ZOU, 1…4 les pistes, la rangée A S D F G H J K les touches blanches (W E R Y U les noires), P PAS. pour brancher un clavier MIDI (Chrome, Edge).

UN VRAI FM-1 ?

ZINZIN s'installe depuis Chrome ou Edge : la page d'installation.
